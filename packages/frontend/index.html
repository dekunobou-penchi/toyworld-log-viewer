操作と定義
リプレイ
下にスクロールしてリプレイの操作が見えなくなると、画面上部に再生バーが出る（ティック番号を入力して Enter で移動、右のボタンで各セクションへ移動）。← → で1ティック、Shift + ← → で10ティック、Space で再生/停止。マップのセルにカーソルでブロックID とエネルギー。プレイヤーをクリックで選択（視界を表示）。
時系列
グラフ上をドラッグで範囲を拡大、クリックでそのティックへ移動。Ctrl/⌘ + ホイール（ピンチ）で拡大縮小、Shift + ホイールか横スクロールで左右に移動。上のバーは枠をドラッグで移動、枠の端で幅を変更。+ / - / 0 キーで拡大 / 縮小 / 全期間。縦軸は全期間で固定。
ティック
各ティックの値は、そのティックで行動を適用する直前の状態と、そこで選ばれた行動（world.jsonl の記録タイミング）。
死亡
Ltime が 0 に戻ったティック。
空振り / 有効率
行動の前提条件（手ぶらで eat しない、正面が空きで get しない など）を満たしたかどうか。toyWorld の action.ts の分岐から判定。同じティックに他のプレイヤーが先に動いた場合はずれることがある。
獲得エネルギー
有効な eat で消費したブロックの、エネルギー表の値の合計。
目標分布との比較
refill（無ければ initMap）のルールが target に使う分布（meta.json の ruleFile.artifacts）とマップの割合を比べる。L1 は ID ごとの割合の差の絶対値の和。偶然の目安は、目標どおりの確率で全マスにばらまいたときに 95% がこれ以下になる L1（モンテカルロ）。偶然の範囲は 2項分布 B(M, p*) の ±2σ。toyWorld の rule-editor の refill プレビューと同じ定義。
補充
events.jsonl の kind = refill。そのティックで選ばれた行動（get / fusion）で起きたものとして、集計の範囲で数える。「ルールの期待」は、そのティックのマップから mixedRefill の確率を計算し直して足したもの。同じティックの他の行動（put など）の影響は追えないので推定。「補充以外のマスの変化」は行動の前後のマップで変わったマスのうち補充でないもの（put、手持ちとの交換など）。
状況
行動を選んだ時点の正面1マス（視界の先頭）の中身と、手持ちの有無。
